Sr. Usuario:
La actual versión de SIPOT 3.15 es compatible con Windows XP o superior (Windows Vista, Windows 7). Para el sistema operativo Windows 8, se encontrará disponible a futuro una nueva versión del aplicativo.
Instructivo de instalación de SIPOT 3.15
El siguiente instructivo le ayudará a decidir el mejor método de instalación basado en sus necesidades. Analizando el escenario actual de su sistema, podemos elegir distintas opciones de instalación.
escenario: 1 | antes: - | instalacion: Se realiza una instalación nueva. El instalador le permite seleccionar la carpeta de destino, donde se guardará SIPOT 3.15. | luego: Queda instalado el aplicativo SIPOT 3.15, en blanco, listo para empezar a usar.
escenario: 2 | antes: Se tiene instalado una versión anterior de SIPOT (1.3, 2.0), con datos cargados de distintos contribuyentes | instalacion: Se realiza una instalación nueva.El instalador le permite seleccionar la carpeta de destino, donde se guardará SIPOT 3.15. | luego: Queda el aplicativo anterior y el nuevo conviviendo en distintas ubicaciones del disco. Los datos de los aplicativos anteriores se pueden migrar a la nueva versión a través del asistente de migración incluido en SIPOT 3.15. Después de migrados, los datos están volcados en el nuevo SIPOT. Las versiones anteriores permanecen hasta que se las desinstale o borre.
escenario: 3 | antes: Se tiene instalado la versión 3 de SIPOT (disponible en la web de DGR desde Julio de 2012), con datos cargados de distintos contribuyentes | instalacion: Se realiza una actualización. No se permite seleccionar la carpeta destino. El nuevo aplicativo se instala en la ubicación de la versión 3. El instalador sobrescribe los archivos viejos con los de SIPOT 3.15, actualizando el aplicativo | luego: Queda SIPOT 3.15 con todos los datos que tenía la versión 3. El aplicativo hace los cambios necesarios para que la base de datos anterior se adapte a las nuevas funcionalidades.
